# Frontend tech lead building fintech at scale: React Native on the surface, Kotlin and Swift underneath.

I lead mobile/frontend engineering at Jupiter Money, a consumer fintech operating at UPI scale in India. My day-to-day spans React Native, native Android, and native iOS (not one with the other two bolted on), and I work in Flutter when the problem fits. Most of what I ship is inside private repos, so this profile is quieter than the work behind it.

## What I build

- Consumer fintech apps handling real money, real scale, real failure modes
- Mobile SDKs and native modules bridging JS and platform code
- Release and CI tooling: signing, store pipelines, build health
- Internal developer platforms and tooling for mobile teams
- AI-assisted engineering workflows for day-to-day development

## Where I go deep

- **React Native**: TurboModules, Fabric, bridging, New Architecture migrations
- **Android**: Kotlin, Java, Gradle, build config, profiling
- **iOS**: Swift, Objective-C, Xcode, CocoaPods
- **Flutter**: Dart, cross-platform UI, build and release analysis
- **Release engineering**: CI/CD, signing, store releases
- **Mobile security**: device integrity, hardening
- **Reliability**: observability, crash investigation, performance profiling
- **Leadership**: technical mentoring, developer experience
